# Credit and AI assistance

The software, documentation and fixed construction witnesses are maintained
by Kaiwen Jin (`yui.ui.siki@gmail.com`). The package implements the local
potential construction accompanying the manuscript *Local potential bases
on Freudenthal meshes*. The original code and exact certificate inputs were
publicly distributed in the [manuscript's accompanying package](https://github.com/yuiyuiui/AIM/tree/f69a9853cae1afc0f82ee4f466c5a53b30709f9a/research/solutions/633-kaiwen-jin-freudenthal-potentials).
This software release adds a documented reusable interface, packaging,
regressions and computed visual examples.

The implementation, API, tests, benchmarks and documentation were produced
by AI agents under Kaiwen Jin's direction. This is AI-created software.
ChatGPT contributed candidate constructions and certificate-producing code;
Codex produced and maintained the software interface, implementation, tests,
benchmarks, documentation, source checks and release preparation. Scientific
attribution and direction remain with Kaiwen Jin. This disclosure does not
assert line-by-line human review. The agents are not independent human
reviewers. Passing software checks does not constitute formal verification,
independent mathematical certification or upstream acceptance.

The finite-element motivation and conjecture are due to Patrick E. Farrell,
Lawrence Mitchell and L. Ridgway Scott; see the primary references in
`docs/method.md`. Their papers are referenced, not redistributed.
NumPy, SciPy, SymPy, Matplotlib and the development tools are external
dependencies and retain their own licenses. No third-party dependency source
or font files are bundled by this package.

The MIT license covers the supplied implementation, documentation, figures
and fixed certificate data. Please retain the author attribution and cite
the software version when using the package in research.
